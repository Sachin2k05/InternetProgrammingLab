# LifeDrop — Lab 23

Local blood donor and blood bank directory with donor registration and profile details, blood group/area search, donor availability and privacy settings, hospital registration, and per-group inventory updates.

Run `python server.py` in this folder, then open [http://localhost:8023](http://localhost:8023).

Demo logins:

- Donor: `donor@blood.test` / `donor1234`
- Blood bank: `center@blood.test` / `blood12345`
- Second blood bank: `river@blood.test` / `blood12345`

Search results do not reveal donor phone numbers. This is a classroom directory, not an emergency or clinical service; contact local emergency services or a hospital for urgent needs.
