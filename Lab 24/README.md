# Wanderlust Travels — Lab 24

Local travel planner with destination, food, lodging, and route details; traveler accounts; accommodation bookings and history; and admin pages for adding travel information and updating booking status.

Run `python server.py` in this folder, then open [http://localhost:8024](http://localhost:8024).

Demo logins:

- Admin: `admin@wanderlust.test` / `wander123`
- Traveler: `traveler@wanderlust.test` / `trip12345`

Bookings and payments are classroom demonstrations. No travel supplier, payment gateway, or external booking service is connected.
