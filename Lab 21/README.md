# CareerBoard — Lab 21

Local job portal prototype with applicant and director registration, admin approval for directors, vacancy search and filters, saved roles, applications with resume notes and privacy scope, director applicant review, and admin reports.

Run `python server.py` in this folder, then open [http://localhost:8021](http://localhost:8021).

Demo logins:

- Admin: `admin@career.test` / `career123`
- Director: `director@career.test` / `director1`
- Applicant: `maya@career.test` / `applicant1`

New directors need admin approval before they can sign in and post roles. Applications and user information are stored in the local `careerboard.db` database.
