# AgriMart — Lab 18

A local classroom marketplace demo for farmers and customers. It includes farmer and customer accounts, demo OTP sign-in, product search and categories, product listings with optional photos, cart editing, saved shipping addresses, wallet top-ups, checkout, order history, and shipping status updates.

## Run it

1. Open a terminal in this folder and run `python server.py` (Python 3 required).
2. Open [http://localhost:8007](http://localhost:8007).

Demo accounts:

- Farmer: `farmer@agrimart.test` / `farm12345`
- Customer: `customer@agrimart.test` / `shop12345`

The sample customer starts with a $10,000 classroom wallet balance and a saved sample shipping address. New accounts receive a demo OTP displayed in the browser; no SMS or email is sent. Wallet payments are simulated locally and do not process real money. This project is for classroom demonstration only.
