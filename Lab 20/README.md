# RentRide — Lab 20

A local vehicle rental prototype with customer registration and login, fleet search by vehicle type and pickup location, date availability filtering, booking/check-in details, reservation status and history, admin vehicle management, booking approval, and customer reviews.

## Run locally

1. Open a terminal in this folder and run `python server.py` (Python 3 required).
2. Visit [http://localhost:8010](http://localhost:8010).

Demo administrator login: `admin@rentride.test` / `rentride123`.

Customers can register from the site. Booking requests begin as **Pending**; the administrator can approve them, mark pickup as checked in, and mark the vehicle returned or the rental completed. Reviews are available for completed rentals. Payment options are simulated and do not process real payments. This project is for classroom demonstration.
